# Codebase audit

Initial source audit: 2026-11-04. Findings below describe the **original baseline**; completion and validation are tracked in `REFACTOR_REPORT.md`.

## Architecture and inventory

This is a React 18.3.1 storefront using Hydrogen 2026.4.7, React Router 7.16.0 framework mode, TypeScript 5.9.3, Vite 8.3.5, Tailwind 4.3.3 and npm. It targets Shopify Oxygen. It is not a Next.js application. `server.ts` creates the Hydrogen request context, dispatches to React Router, commits session changes and resolves Shopify redirects after 404 responses. `app/entry.server.tsx` streams SSR with a nonce-based CSP; `app/entry.client.tsx` hydrates in Strict Mode.

`app/root.tsx` loads cart, shop analytics, consent and unused header/footer menus. `PageLayout` provides shared overlay state, route transitions, search/cart dialogs and a controller footer. Components already have sensible feature folders; moving the entire tree would not help.

| Route                                                     | Responsibility and dependencies                                                                           |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `/`                                                       | Static logo/MainMenu; unused featured/recommended queries in loader                                       |
| `/merch`                                                  | Catalog query, selection header, 12-product grid                                                          |
| `/merch/:handle`                                          | Nested product dialog; server-selected/optimistic variant, product theme, description, quantity, CartForm |
| `/drumkits`                                               | Collection with `drumkits` handle; intentional “Coming soon” fallback                                     |
| `/search`                                                 | Predictive-search resource loader, consumed by debounced SearchScreen                                     |
| `/cart`                                                   | Cart mutation action; no standalone page component                                                        |
| `/cart/:lines`                                            | Shopify cart permalink; creates cart and redirects to checkout                                            |
| `/discount/:code`                                         | Applies code, then redirects                                                                              |
| `/info`, `/info/:section`                                 | Information menu with external links and published Shopify policies                                       |
| `/robots.txt`, `/sitemap.xml`, `/sitemap/:type/:page.xml` | SEO resource routes                                                                                       |
| `/*`                                                      | Throws real 404, root error boundary renders NotFoundPage                                                 |

No account screens, collection filters/sorting, contact forms, customer hooks or custom payments are implemented. These are outside this refactor, not defects. `orderFilters.ts` and customer codegen are leftover account scaffolding.

State is mostly local: MainMenu owns selection/input mode; listing selection owns header/id; PDP owns quantity; Aside context coordinates the HUD and overlays. Hydrogen owns cart mutations, optimistic cart and optimistic variants. Search uses a keyed React Router fetcher and suppresses responses whose term no longer matches. Effects are mostly appropriate browser integrations (audio, focus, listeners, timers). Keep their cleanup and the intentional animation timing.

Styles comprise Tailwind theme/utilities, global resets and a dedicated PS2 effects stylesheet. Reviewed all source routes, components, hooks, utilities, GraphQL fragments, CSS, entries and configuration, plus the checked-in search guides. Generated API declarations and lockfile were inspected for types/versions rather than treated as authored code. No existing tests or runner are present.

## Baseline checks

- `npm run lint`: passed.
- `npm run typecheck`: passed, with dependency deprecation/future-flag warnings.
- `npm run build`: bundles generated, but CLI printed a codegen error for an absent customer-account documents directory. The CLI did not propagate that error as a failing exit code. This is not a clean build/codegen baseline.
- Prettier check of app/config: six files flagged (including the favicon manifest).
- No unit/component/integration/E2E scripts, test files or quality gate before deployment.
- Source findings have not yet been verified in a browser at this initial checkpoint. Regression tests will distinguish reproduced behavior from source-level risks.

## Principles and execution batches

Preserve React Router route filenames, generated Shopify types, Oxygen entry, SSR nonce handling, CartForm/cart cookie behavior, optimistic hooks, existing theme/visual effects and normal animation durations. No framework upgrade, repository-wide rename, new state library or generic service layer is justified.

| ----------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------ |
| 1: foundations                      | package/config, test fixtures, CI                             | Deterministic unit/component/route/browser tests before behavior changes    | Low    | Characterize URLs, descriptions, themes, search normalization, cart dispatch, product loaders; lint/typecheck/test/build |

| 3: purchase UI and overlays         | product/cart/search/dialog/menu components                    | Correct currency/options, focus/scroll cleanup, visible async errors        | Medium | Component interactions, desktop/mobile E2E, keyboard and failure cases; tests/typecheck/lint/build                       |
| 4: simplification and documentation | root/home loader, unused scaffold, conventions/testing/report | Remove unnecessary work and codify final conventions                        | Low    | Full tests, coverage, lint, formatting, typecheck, clean codegen and production build                                    |

Each batch will be reviewed against its tests before continuing. Ordinary automated tests must not call a live Shopify store. Browser fixtures should exercise actual route loaders/actions and Hydrogen SSR with a separate test-only worker, never a production runtime switch. Live Shopify/checkout integration and assistive-technology validation must remain explicitly unverified if no dedicated environment is supplied.

## Findings confirmed during execution

- **A17 — Medium:** Browser console reported “A router only supports one blocker at a time” when leaving a product. Both PageLayout's RouteFadeTransition and ProductDetailRouteView registered blockers. Consolidated ownership in RouteFadeTransition; product exit consumes shared state. Browser checks cover absence of the warning and preserved 0.3/0.4/0.5 second CSS durations; hook tests cover timer progression, reduced motion and unmount cleanup.
- **A18 — Medium:** Product metadata returned empty title/description for empty Shopify SEO strings, and canonical descriptors across the catalog/content routes omitted React Router's `tagName: 'link'`. Regression test reproduced the empty descriptors. Added fallback strings, actual link descriptors and an absolute product canonical URL; verified emitted browser metadata.
- **A19 — Medium, unresolved design issue:** Full axe scans report a serious color-contrast violation for the dim search status text. Structural dialog checks pass separately. Preserve the requested visual treatment for this pass and explicitly track the contrast choice; this is not a claim of WCAG conformance.
- **A20 — High, unresolved dependency issue:** `npm audit --omit=dev` reports advisories in the pinned React Router release line. Hydrogen 2026.4.7 declares `react-router` and `@react-router/dev` peers as `~7.16.0`; a forced upgrade to the suggested 7.18.x release violates that compatibility contract. Plan a coordinated Hydrogen/router migration. No live exploit was attempted. Lodash's compatible update command reported “up to date”; do not claim its advisory was patched.
